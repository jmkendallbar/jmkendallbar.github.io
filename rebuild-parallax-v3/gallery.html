Gallery

A portfolio archive of illustration, photography, animation, maps, comics, books, and data visualization. This rebuild intentionally removes the old storefront behavior from the public site. Gallery protection

No public website can fully prevent saving images once they are displayed in a browser. The practical approach is deterrence: serve lower-resolution web files, overlay captions/watermarks, disable casual right-click/drag behavior, and keep original files private.

Protected display gallery

This gallery uses background images, overlays, and no-save interaction as casual download deterrents. Use this as a layout scaffold; swap in watermarked/compressed assets before deployment.
